| [`banner-light.svg`](banner-light.svg) | Bannière du README, thème clair |

Les bannières sont sélectionnées automatiquement par GitHub selon le thème du lecteur (`<picture>` + `prefers-color-scheme`). Couleurs : `#1877F2` (bleu), `#42B72A` (vert), `#F7B928` (jaune), `#E41E3F` (rouge).
